[CI run 41225146672](https://github.com/patrick-hudson/put.gd-desktop/actions/runs/41225146672),
the newest successful CI run on `nightly` when collected on 2026-10-31.
The run started at 17:33:59 UTC. Its manifest records source commit
`8694706f3ae3e357f9bb3eb1f999f44a4ed278e4`, tree
`f9c5d5de1cc05e10416a77f5ad74f4ac1ee6e632`, and build

not real-desktop acceptance evidence. The catalog includes a deliberately fixed

## Generated artwork

| File | What it is |
| --- | --- |
| `logo.svg` | The application icon from `packaging/linux/putgd.svg` (the IconArt arrow-and-tray glyph) with a soft glow, on a padded viewBox |
| `banner-dark.svg`, `banner-light.svg` | Hero banner: the icon tile, wordmark, tagline and capability pills. The light file is the dark file with its palette swapped; GitHub picks one through `<picture>` and `prefers-color-scheme` |
| `flow.svg` | The five-stage pipeline animation (trigger, source, optional edit or review, upload, done) cycling through three scenarios on a 24-second loop: a hotkey screenshot, clipboard files from the tray menu, and a CLI-started screen recording that goes through review. ## Icons

`icons/*.svg` are the section and feature icons: the brand tile (`#1b1e25`,
corner radius 5 on a 24-unit grid) with a duotone glyph placed exactly as the
application icon places its own (`translate(2.4 2) scale(.8)`), accent
`#9bbcff` and secondary `#526386`. `capture`, `edit`, `record`, `storage`
(destinations), `history`, `desktop`/`desktops`, `screenshots` (image) and
`docs` (file) transcribe the glyphs in `src/ui/IconArt.cpp`; `features` and
`download` are the Lift arrow-and-tray glyph and its downward mirror; the rest
(`scriptable`, `quiet`, `quickstart`, `build`, `releases`, `architecture`,
`shield`, `contributing`, `license`, `search`) are drawn in the same two tones and stroke
weights. They are generated by a small Python script kept out of the tree; edit
the SVGs directly or regenerate the whole set.

## Screenshots

All screenshots were taken on 2026-10-18 from the nightly build
`0.1.1-dev.343+gac92b2158535` (nightly commit `ac92b21`), running on
sanitised desktops with nothing but put.gd open:

| Desktop | Where | How the build got there |
| --- | --- | --- |
| Linux Mint Cinnamon / X11 | the lab's `cinnamon-x11` QEMU guest on the Fedora builder (1280×800) | CI package `putgd_0.1.1~dev.343+gac92b2158535_amd64.deb` from the nightly push run, installed with `tools/lab/lab.py install` |
| Fedora 44 GNOME 50 / Wayland | the physical Fedora builder desktop (1920×1080) | `cmake --preset dev` scratch build of the same commit, run with the packaged host Shell extension |
| Debian 13 KDE Plasma 6.3 / Wayland | the physical Debian builder desktop (1920×1080) | `cmake --preset dev` scratch build of the same commit, with the restricted KWin desktop entries for the scratch binaries |

Each instance ran with isolated XDG directories and a lab configuration:
local copies on, an S3 destination named `put.gd` with no credentials (the
development template's non-secret settings), and shortcuts `Ctrl+Shift+1`
to `Ctrl+Shift+6`. Nothing was uploaded anywhere; every History entry is a
local-only capture, the edited photo, or a six-second local recording.

The photo in the editor is NASA's *Blue Marble* image of Earth
(NASA image ID `PIA18033`, `images-assets.nasa.gov/image/PIA18033/PIA18033~medium.jpg`),
a public-domain NASA work. The annotations are the editor's own shapes.

Frames were captured through the lab's VNC/QMP witnesses and cropped with
Pillow (`Image.crop`, `optimize=True`); the composite images are built with the
same library. The raw frames were not retained in the repository. The README
claims no acceptance result from these images; acceptance evidence lives under
`docs/evidence/` and is recorded in `docs/verification.md`.
