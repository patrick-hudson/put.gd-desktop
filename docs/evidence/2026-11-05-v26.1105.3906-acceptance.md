## Desktop check
Thirteen cells on each desktop, run by `tools/lab/nightly_desktops.py --stable-draft`.

| Desktop | Package | Result |
| --- | --- | --- |
| Mint Cinnamon X11 | Ubuntu 24.04 DEB | 13 of 13 |
| Ubuntu GNOME Wayland (VM) | Ubuntu 26.04 DEB | 13 of 13 on rerun |
| Kubuntu Plasma | Ubuntu 26.04 DEB | 13 of 13 |
| Aurora Plasma Wayland (VM) | AppImage | 13 of 13 |
| Fedora GNOME Wayland | Fedora 44 RPM | 13 of 13 |

The Ubuntu GNOME row first lost its guest session at `upload_clipboard-1`, which left a resident running and failed most later cells in that row. A rerun on the same files, with no change, passed 13 of 13. The cause isn't known, and a rare existing app problem isn't ruled out (#1214). No app source differs from `v26.1104.3892-nightly`, which passed this row. Aurora's test tools came through the `dnf` fallback from #1207, because Fedora's `updates-archive` repository was still broken.

## Native packages
Each package installed over `v26.1104.3892-nightly`, upgraded to the draft, was removed, then installed fresh on an empty profile.

| Asset | Target | Result |
| --- | --- | --- |
| Ubuntu 24.04 DEB | Mint 22.3 Cinnamon X11, VM | Passed |

Configuration, history and saved files survived upgrade and removal. Removal cleared binaries, desktop entries and managed startup files, with no process left. DEBs keep the apt source conffile until purge, and the RPM removes its repository file, both as documented.

A first Fedora run failed with `helper_unavailable` because it saved before the documented GNOME login and extension setup. A second run with that setup done passed. An RPM upgrade keeps the nightly repository channel, per the documented first-install-only behavior, while a fresh install selects stable.

**Not tested here:** upgrading with the resident running, automatic launch at login, cleanup of inactive accounts, and capture or recording after upgrade. These runs used synthetic local saves.

## Multi-head VM
A Cinnamon X11 guest with two independent 1280×800 heads. A 1280×40 region crossing the boundary between the heads captured the right colors from both: all 51,200 pixels matched, and an independent paste matched exactly.

## Accepted exceptions
- **SQLite 3.53.4 in Qt 6.12.0's driver, AppImage only (#1210, expires 2027-02-03).** Three High CVEs with a fix in 3.54.0, and no Qt release carries it. The session extension isn't compiled. FTS5 ships, but put.gd doesn't reach it. Patrick accepted this on 2026-11-05.
- **HarfBuzz in Qt 6.12.0, AppImage only (#1070, expires 2027-01-29).** Affected code isn't compiled.
- Existing audited FFmpeg and ICU dispositions (#511).
- Limitations listed in `CHANGELOG.md`, accepted 2026-11-04.

The builder audit above is the gate this release relies on. #1213 installs those libraries for the next release, and isn't proven until then.
