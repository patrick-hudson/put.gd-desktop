Pass means the result assertions succeeded. Blocked means the driver or fixture refused before the required proof; it does not establish an app defect. The cumulative table selects the successful focused replays rather than hiding earlier failed attempts. Raw per-run receipts retain those failures. `phase-a.json` maps every final cell to its exact run, sandbox, receipt, frames and operation/history IDs. Its Cinnamon browser cell deliberately overrides the older raw functional pass: navigation matched, but the retained frame has no visible pixels. The final code now blocks that case.

Capture uses the frozen test player's independent pre-capture VNC image as the oracle. Window and desktop outputs are 1280×800 and match pixel for pixel at scale 1, with zero tolerance; alpha, black output, foreign overlays and shifts are rejected. Region dragging is blocked before input by [#942](https://github.com/patrick-hudson/put.gd-desktop/issues/942). No multi-monitor or scaled-desktop acceptance is claimed.

Recording prepares the known 640×320 source rectangle through the production session API, then uses real Start, Stop and explicit Upload. This proves the recording outcome, not Tier 2 selector gestures. The exact uploaded file is decoded again and compared with a separate frozen control. Cinnamon: moving score 60.322, frozen .018, duration 6200 ms, uploaded/local SHA `bbe708a118e4784c402012adb3dd2936c4f0c3a3efd34be417ec27222910b82f`. GNOME: moving 64.180, frozen .017, duration 6866 ms, SHA `48eb6af3a1d100b8d5fcc4847c0d7c05939f9306ab5affbba96e39a26fe64751`. Both satisfy the declared 4–30 second range. KDE reaches a portal fallback and blocks at the unobserved `Share` control, [#822](https://github.com/patrick-hudson/put.gd-desktop/issues/822). Its retained frame is fully privacy-masked; that limitation remains, and no visible chooser or valid clip is claimed.

Editing uses real mouse gestures for the arrow, rectangle, text anchor and solid redaction, plus real typing and Upload. The raster oracle checks placement within four stroke/quantization pixels, a declared font-bearing band for text, solid black redaction interiors, opaque output and no changes elsewhere. The tightened final oracle was rechecked against all three retained real exports. [Cinnamon export](cinnamon-edit-export.png) shows the actual result. Their upload/local hashes are in the receipts; no mocked image is desktop proof.

History deletion uses the exact uploaded row, a real context menu, readback of its exact prepared ID/effects, and a real confirmation click. Independent HTTP GET returns 404 while the loopback server is still alive. The corrected Cinnamon replay uses the existing native accessible-button lookup (`Delete 1 file`), which supports Qt 6.4. GNOME/KDE earlier successful confirmations used the object-id lookup. Final deletion IDs: Cinnamon `5ecd330b-fcff-485b-a2b7-4cefcbb88ca9`, GNOME `9bab2786-590c-44fb-b04e-fa51c97f1ba2`, KDE `3b16f268-72d9-42a8-a1a1-a80409590f51`. No live object or bucket configuration was touched.

Cinnamon's real guarded Firefox matched the copied upload URL and image content; its MIME backups restored with matching hashes. The retained [full-screen frame](cinnamon-firefox-masked.png) is black, so visual proof is blocked by [#952](https://github.com/patrick-hudson/put.gd-desktop/issues/952), with mask provenance in [cinf-masks.json](cinf-masks.json). GNOME and KDE stop before paste because the normal owned-window geometry guard cannot bind the private Snap Firefox, [#951](https://github.com/patrick-hudson/put.gd-desktop/issues/951). Cause remains unproven; no title-only, guessed-coordinate or ownership bypass was used.

Aurora starts and identifies the exact clean AppImage, but all six flows stop before outcome work because `org.freedesktop.secrets` already belongs to `ksecretd` (PID 1974). The existing fixture correctly refuses to replace it. [#955](https://github.com/patrick-hudson/put.gd-desktop/issues/955), related to #919, tracks this snapshot/fixture prerequisite. No wallet contents were read or modified. Each flow retains a masked frame; a separate visible idle desktop is retained too. No capture, recording, browser or deletion success is inferred for Aurora.

Aurora's standard driver packages were added only in the overlay, with dry-run proof of no desktop/compositor/portal upgrade. Native Firefox could not resolve against the pinned NSS, so standard Flatpak Firefox 159.0 was installed. A normal `systemctl reboot` activated the eight driver dependency packages after the session reboot helper's QMP reset left them unactivated. That failed preflight and its corrected command are retained. The newer AT-SPI service exposes only `IsEnabled`, so the staging helper's unconditional `ScreenReaderEnabled` read fails, [#954](https://github.com/patrick-hudson/put.gd-desktop/issues/954). A narrow observed-property setup enabled only `IsEnabled`, verifying every other reported property was unchanged. Final preflight has no missing tools. `uupd.timer`/service were stopped. The official AppRun and driver's private `XDG_DATA_HOME` supplied the KWin permission entry.

Five sandboxes were created, at most two concurrently. All used the requested hydrated snapshots, KVM, short checked socket paths, private app directories, visible wall tunnels and saved frames. Goldens were never booted or modified. The Aurora helper's documented run-specific read-only keyseed was layered above its immutable cloud golden. Every run disk was exported and its manifest/archives verified before guarded retirement. Full bulk evidence, source versions, PNG/MP4 payloads, failed attempts, exact identities and cleanup/deletion receipts remain private under `work/campaigns/surface-driver-20261029/tier1-phase-a-sol-7f191320`; no test source was deleted to reduce evidence. Only sanitized receipts and selected policy-masked frames are committed here.

The code's five fault-injection unit tests pass both as a module and through the direct script command used by CI. CI initially caught the direct-import-path mistake; the final code fixes it. On the sandbox the borrowed suites ran 130 tests: 129 passed and one was missing an export input (`tests/gui/ui_catalog.cpp`); copying that source input and rerunning that exact test passed. Initial workstation OCR-dependent suite attempts lacked tesseract and were not desktop proof. Tesseract was installed on each sandbox host; the workstation received no toolchain or package installation.

The harness evolved during development; these are cumulative result proofs on one exact app build, not a claim that every desktop ran the final recipe commit in one identical campaign. Earlier exported recipe sources have independent SHA-256 identities in `phase-a.json`.
