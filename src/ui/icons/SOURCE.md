The check glyph is authored for put.gd. The SVG keeps the vector source; the bundled PNG and @2x PNG keep it visible with the minimum distro Qt Widgets packages, without requiring an SVG image plugin. putgd-record's overlays use it (src/record/record.qrc). The interface paints its check, radio and chevron indicators from the theme tokens instead (Ui::indicators, #60), so they follow the dark and light schemes.
