put.gd package dependency notice

Qt 6 and QtKeychain are dynamically linked distribution packages. Their licenses,
source and security updates are supplied through the distribution package manager.
Qt platform plugins and SQLite SQL driver remain distribution owned.

The official AWS SDK for C++ and its CRT shared libraries are privately installed
under the putgd library directory. Pinned source identities are recorded in
/usr/share/putgd/dependency-lock.json. AWS SDK and CRT Apache-2.0 license texts are
installed alongside this notice; s2n-tls uses Apache-2.0. Rebuild the pinned official
SDK following docs/build.md, update the lock deliberately, and rebuild the DEB to
update these libraries. No compiler or Qt runtime is bundled.

The ext-data-control-v1 Wayland protocol notice is retained in
wayland-ext-data-control-v1.xml beside this file, including its original
copyright and permission text. Generated client bindings use that protocol.

Native packages include desktop integration assets and dependency notices. Release
artifacts have build identities, package inventories and published checksums. Verify
these against the exact artifact being installed. Installation and artifact auditing
alone do not certify compositor support or install/upgrade/removal behavior; consult
https://github.com/patrick-hudson/put.gd-desktop/blob/main/docs/verification.md
and https://github.com/patrick-hudson/put.gd-desktop/blob/main/docs/release.md
for tested versions and remaining gates, including the complete release license audit.
